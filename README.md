# SaysWho

A security gateway for AI agents. It is one Go binary that sits between an agent and its tools over the
Model Context Protocol, and asks of every risky value: who said that?

**Status: under construction. Nothing is measured yet.** The numbers in [docs/DESIGN.md](docs/DESIGN.md)
are forecasts from scripts that read published AgentDojo logs. They are not results from this gateway.

Similar gateways already exist, and this one is not a guarantee: the design lists what it cannot stop.
No independent security audit has been done.
